Session 1 – Choosing a Business Idea and Setting Up GitHub

I began this project by brainstorming different startup ideas using ChatGPT. After considering several options, I decided to create CampusMarket, an online marketplace where university students can buy and sell affordable second-hand campus and living essentials.

The purpose of CampusMarket is to help students save money while providing an easy way to sell items they no longer need. The marketplace includes textbooks, furniture, clothing, electronics and living essentials.

I created a public GitHub repository called Campus-Market and added a README file with a short description of my business.

Session 2 – Building the Initial Website

I used ChatGPT to generate the initial website code using HTML and CSS. I created a file called index.html and pasted the generated code into GitHub.

The first version of my website included:

A forest green and cream colour scheme.

A homepage introducing CampusMarket.

Navigation links.

Four fictional product listings.

Information about the benefits of using CampusMarket.

A footer identifying the website as a student prototype.

The first problem I encountered was that only the first line of code pasted into GitHub. I solved this by copying the entire code block and replacing the incomplete code.

Once the code was entered correctly, I committed the changes directly to the main branch.

I went into the repository settings, selected Pages and chose to deploy the website from the main branch using the root folder.

Demonstrating Network Effects

One of the most important features of my prototype is the interactive network effects simulator.

The simulator allows users to adjust the number of active sellers and observe how the number of available listings and potential buyers increases.

The simulation assumes that each seller contributes three listings and is associated with four potential buyers. These numbers are hypothetical and are used for educational purposes rather than representing actual market research.

CampusMarket demonstrates two-sided network effects because buyers and sellers benefit from each other's participation. More sellers provide buyers with a greater selection of products, while more buyers create additional selling opportunities for sellers.

What a Real Version Would Need

Although the current prototype demonstrates the main functions of CampusMarket, additional technology and resources would be required to operate it as a real business.

A real version would require:

Secure user accounts and student verification.

A cloud database to permanently store listings and user information.

Individual product image uploads.

A messaging system for buyers and sellers.

Secure payment processing if online payments were introduced.

Cybersecurity measures to protect customer information.

Reporting and moderation tools to prevent scams and inappropriate listings.

Customer support to resolve problems between buyers and sellers.

Marketing strategies to attract students to the platform.

Regular website maintenance and software updates.

The current prototype does not collect personal information or process real payments. Listings and reservations are temporary and reset when the page is refreshed.

Final Reflection

Before starting this project, I had limited experience with GitHub and website development. Using AI made the process more accessible because I was able to create a functional website without having to write all the code myself.

One of the biggest challenges was learning how to navigate GitHub, create files, commit changes and publish a website. Although AI generated the code, I still had to understand where to enter it, how to update it and how to test whether the features worked.

This project demonstrated that AI can reduce the time, cost and technical knowledge required to create a business prototype. However, creating a website does not automatically mean that a business will become successful.

Another entrepreneur could use AI to create a similar marketplace with almost identical features. Therefore, the website itself would not provide CampusMarket with a strong competitive advantage.

Instead, the long-term success of CampusMarket would depend on attracting students, building trust within university communities, developing relationships and creating an active network of buyers and sellers.

I also learned the importance of testing AI-generated software. Although AI was able to generate a functional website, the mini fridge displaying a light bulb showed that AI-generated code can still have limitations that require human attention.

Overall, this project helped me understand how technology can support entrepreneurship. AI can make starting a business easier, but entrepreneurs still need to identify customer problems, make business decisions, manage risks and develop advantages that competitors cannot easily copy.

# CampusMarket

### Student living, made affordable.

## Project Overview

CampusMarket is an online student marketplace designed to help university students buy and sell affordable second-hand campus and living essentials.

This project was developed for the BSAD 281 AI to Startup assignment using ChatGPT and GitHub.

## Website Features

- Interactive student marketplace
- Product search bar
- Category filters
- Price sorting
- Create new product listings

- Interactive network effects simulator

## Project Status

This website is an educational business prototype. Product listings and reservations are simulated, and no real payments are processed.
